# Концепция системы

## Что мы делаем

Система — **программный финансовый аналитик** для оценки компаний и индустрий.

По запросу на тикер или индустрию она:

1. Собирает фундаментальные, рыночные и макро-данные.
2. Считает справедливую стоимость (fair value) **несколькими независимыми методами**.
3. Сравнивает справедливую цену с текущей и формирует вердикт.

## Ключевой принцип: детерминизм через Go

Весь runtime — **чистый Go-код**. Никаких LLM-вызовов в момент анализа тикера или индустрии.

- **LLM используется только на этапе разработки и анализа**: проектирование методов оценки, разбор отчётности новых эмитентов, исследование индустрий, генерация кода и формул.
- **Runtime детерминирован**: одинаковые входы → одинаковый результат. Любую цифру в отчёте можно перепроверить вручную.

## Что система оценивает

- **Компании** — fair value по нескольким методам, сравнение с рынком, health-check.
- **Индустрии** — агрегированные метрики, сравнительная оценка эмитентов внутри индустрии.

## Что система НЕ делает

- Не торгует и не отправляет ордеров.
- Не использует LLM в realtime-обработке.
- Не заменяет решение человека — это инструмент аналитика.

# `operation_metrics`

**Назначение:** справочник операционных показателей — список всех `operation_metric_id`, по которым FM собирает временные ряды (используется в разделе `operations` карточки эмитента). Без пагинации.

**URL:** `GET /api/fm/v2/operation_metrics`

## Query-параметры
Нет.

## Пример запроса
```
GET /api/fm/v2/operation_metrics
```

## Поля JSON-ответа
Массив объектов:

| Поле | Тип | Смысл |
|---|---|---|
| `id` | str | Идентификатор метрики (`aprs`, `gmv_incl_services`, `audience`, …) — соответствует `operation_metric_id` в разделе `operations` карточки эмитента |
| `name` | str | Название метрики на русском |
| `description` | str | Подробное описание (может быть пустым) |
| `unit` | str | Единица измерения (`₽`, `шт`, `чел`, `m2`, `t`, `%`, …) |
| `amount` | int | Множитель к значению `value` (например `1000000` означает «значение в миллионах единиц») |

## Пример ответа (фрагмент)
```json
[
  {
    "id": "aprs",
    "name": "ARPC (крупные клиенты в России)",
    "description": "ARPC — средняя выручка на одного клиента",
    "unit": "₽",
    "amount": 1
  },
  {
    "id": "gmv_incl_services",
    "name": "GMV вкл. услуги",
    "description": "GMV вкл. услуги",
    "unit": "₽",
    "amount": 1000000
  }
]
```

## Edge cases
- Эндпоинт возвращает **полный** справочник (на момент тестирования — несколько сотен метрик); если нужен один `id`, фильтруй на стороне клиента.
- Истинное значение метрики в разделе `operations` карточки эмитента уже умножено на `amount` в поле `value` (а `original_value` хранит «как в отчёте» эмитента).

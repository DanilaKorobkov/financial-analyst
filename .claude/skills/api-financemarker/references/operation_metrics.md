# `operation_metrics`

**Назначение:** справочник операционных KPI — словарь всех `operation_metric_id`, по которым FM собирает временные ряды (используется для расшифровки раздела `operations` в карточке эмитента).

**URL:** `GET /api/fm/v2/operation_metrics`

## Query-параметры

| Имя | Тип | Обязательность | Описание |
|---|---|---|---|
| `api_token` | str | required | API-токен (см. SKILL.md → «Авторизация»). |

> `limit` / `offset` сервером **игнорируются** — эндпоинт всегда возвращает полный справочник (на 2026-05-11 — несколько сотен метрик).

## Пример запроса
```
GET /api/fm/v2/operation_metrics?api_token=$FINANCE_MARKER_TOKEN
```

## Поля JSON-ответа
Массив объектов:

| Поле | Тип | Смысл |
|---|---|---|
| `id` | str (snake_case) | Идентификатор метрики (`aprs`, `gmv_incl_services`, `audience`, `car_loans`). Совпадает с полем `operation_metric_id` в разделе `operations` карточки эмитента → ключ для join. |
| `name` | str | Название метрики на русском, для отображения пользователю (`ARPC (крупные клиенты в России)`). |
| `description` | str | Развёрнутое описание метрики. Может быть пустой строкой или повторять `name`. |
| `unit` | str | Единица итогового значения после применения множителя: `₽`, `шт`, `чел`, `m2`, `t`, `%`, `декалитр`. |
| `amount` | int | Множитель: на сколько умножено хранимое в `operations.value` значение относительно «как в отчёте». `1` — единицы, `1000000` — миллионы (т.е. `value` в `operations` уже «в штуках», а `original_value` — «в млн штук»). |

## Пример ответа (фрагмент, реальный)
```json
[
  {
    "amount": 1000000,
    "description": " Общие отгрузки (декалитров).",
    "id": "general_shipments",
    "name": " Общие отгрузки (декалитров)",
    "unit": "декалитр"
  },
  {
    "amount": 1,
    "description": "ARPC - средняя выручка на одного клиента",
    "id": "aprs",
    "name": "ARPC(крупные клиенты в России)",
    "unit": "₽"
  },
  {
    "amount": 1000000,
    "description": "GMV вкл. услуги",
    "id": "gmv_incl_services",
    "name": "GMV вкл. услуги",
    "unit": "₽"
  }
]
```

## Edge cases
- Эндпоинт возвращает **весь** справочник (фильтрации по `id` нет). Если нужен один `id`, фильтруй на стороне клиента.
- Поле `description` иногда дублирует `name` или содержит лишний пробел в начале (см. `" Общие отгрузки …"`) — нормализуй на клиенте.
- В разделе `operations` карточки эмитента `value` уже умножено на `amount`, а `original_value` хранит «как опубликовал эмитент». Не умножай повторно.

# `token_info`

**Назначение:** информация по текущему API-токену — остаток единиц доступа на сегодня и срок подписки.

**URL:** `GET /api/fm/v2/token_info`

## Query-параметры
Нет.

## Пример запроса
```
GET /api/fm/v2/token_info
```

## Поля JSON-ответа
Объект:

| Поле | Тип | Смысл |
|---|---|---|
| `day_limit` | int | Остаток единиц доступа до конца дня. На каждый запрос-ответ списывается 1 единица. |
| `valid_to` | str (date, `YYYY-MM-DD`) | Дата окончания подписки. После — все эндпоинты вернут 403. |

## Пример ответа
```json
{
  "day_limit": 399,
  "valid_to": "2026-09-28"
}
```

## Edge cases
- 401 / 403 → токен невалидный или подписка просрочена.
- Сам вызов `token_info` **расходует** 1 единицу `day_limit` (как и любой другой). Не дёргать в цикле.

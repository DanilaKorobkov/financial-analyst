# `token_info`

**Назначение:** информация о текущем API token — остаток единиц доступа на сегодня и срок подписки.

**URL:** `GET /api/fm/v2/token_info`

## Query-параметры

| Имя         | Тип | Обязательность | Описание                            |
| ----------- | --- | -------------- | ----------------------------------- |
| `api_token` | str | required       | API-токен из профиля FinanceMarker. |

## Пример запроса

```http
GET /api/fm/v2/token_info?api_token=$FINANCE_MARKER_TOKEN
```

## Поля JSON-ответа

Объект:

| Поле        | Тип                      | Смысл                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `day_limit` | int                      | Согласно swagger FM — «остаток единиц доступа до конца текущего дня». На практике значение отстаёт от реального счётчика из-за серверного кеша (наблюдалось расхождение с UI в десятки единиц). По достижении 0 эндпоинты возвращают 403. Для точного остатка смотри UI личного кабинета. Модель тарификации — см. [`SKILL.md`](../SKILL.md) → «Авторизация». |
| `valid_to`  | str (date, `YYYY-MM-DD`) | Дата окончания подписки. Начиная со следующего дня все эндпоинты возвращают 403 даже при ненулевом `day_limit`.                                                                                                                                                                                                                                               |

## Пример ответа (реальный, 2026-05-11)

```json
{
  "day_limit": 399,
  "valid_to": "2026-09-28"
}
```

## Edge cases

- По эмпирическим замерам (сессия 2026-05-14) `token_info` фактически бесплатен — десятки последовательных вызовов не двигали ни ответное `day_limit`, ни реальный счётчик в UI. Похоже на серверный кеш самого ответа `token_info`. На обещание «1 вызов = 1 единица» полагаться нельзя, но и злоупотреблять не нужно — на стороне Go-runtime лучше кешировать значение.
- Поле `day_limit` в ответе отстаёт от реального остатка квоты (в одной из сессий API стабильно отдавал `399`, тогда как UI личного кабинета показывал движение от `383` до `294`). Для точного остатка — UI.

# `token_info`

**Назначение:** информация о текущем API token — остаток единиц доступа на сегодня и срок подписки.

**URL:** `GET /api/fm/v2/token_info`

## Query-параметры

| Имя         | Тип | Обязательность | Описание                            |
| ----------- | --- | -------------- | ----------------------------------- |
| `api_token` | str | required       | API-токен из профиля FinanceMarker. |

## Пример запроса

```http
GET /api/fm/v2/token_info?api_token=$FINANCE_MARKER_TOKEN
```

## Поля JSON-ответа

Объект:

| Поле        | Тип                      | Смысл                                                                                                                                                                                                                                                                                                                                       |
| ----------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `day_limit` | int                      | Согласно swagger FM — «остаток единиц доступа до конца текущего дня». На практике значение отстаёт от реального счётчика (в одной сессии API стабильно отдавал `399` при движении UI от `383` до `275`). По достижении 0 эндпоинты возвращают 403. Точный остаток — в UI личного кабинета. Модель тарификации — [`billing.md`](billing.md). |
| `valid_to`  | str (date, `YYYY-MM-DD`) | Дата окончания подписки. Начиная со следующего дня все эндпоинты возвращают 403 даже при ненулевом `day_limit`.                                                                                                                                                                                                                             |

## Пример ответа (реальный, 2026-05-11)

```json
{
  "day_limit": 399,
  "valid_to": "2026-09-28"
}
```

## Edge cases

- Значение `day_limit` в ответе отстаёт от реального счётчика квоты (наблюдалось стабильное `399` при параллельном движении UI на десятки единиц). Для точного остатка — UI личного кабинета.
- По эмпирическим замерам сам `token_info` фактически бесплатен — десятки последовательных вызовов не двигали реальный счётчик. Кешировать значение на стороне Go-runtime всё равно стоит, чтобы не зависеть от частоты обновления.
- Модель списания `day_limit` (тариф за блок в `include`, серверный кеш, ключ кеша) — см. [`billing.md`](billing.md).

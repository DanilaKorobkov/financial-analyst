# `get_market_candles`

**Назначение:** получить свечи HLOCV по бумаге **на рынке** (по всем основным режимам). Ответ разбит на страницы — блоки по 500 строк отдаются через `start=<offset>`; склейка на стороне клиента.

**Reference ISS:** <https://iss.moex.com/iss/reference/155>

## URL

```http
GET https://iss.moex.com/iss/engines/{engine}/markets/{market}/securities/{TICKER}/candles.json
```

**Форма ответа:** блок `candles` с пагинацией через `start` (+ `history.cursor` где применимо).

**Базовые query-параметры ISS** (общие для всех эндпоинтов, в reference не дублируются — см. SKILL.md): `iss.json=extended`, `iss.meta=off`, `iss.only=<block>`, `<block>.columns=<csv>`, `start=<offset>` для пагинации.

### Параметры

| Имя               | Тип        | Обязательно | Дефолт | Описание                                                                    |
| ----------------- | ---------- | ----------- | ------ | --------------------------------------------------------------------------- |
| `{TICKER}` (path) | str        | да          | —      | Тикер бумаги                                                                |
| `interval`        | int        | нет         | `24`   | Размер свечи (см. таблицу ниже)                                             |
| `from`            | YYYY-MM-DD | нет         | —      | Начало диапазона; пусто = с начала истории                                  |
| `till`            | YYYY-MM-DD | нет         | —      | Конец диапазона; пусто = до текущего дня (для сегодня — недозакрытая свеча) |

### Кодировка `--interval`

| `interval` | Размер свечи              |
| ---------- | ------------------------- |
| 1          | 1 минута                  |
| 10         | 10 минут                  |
| 60         | 1 час                     |
| **24**     | **1 день (по умолчанию)** |
| 7          | 1 неделя                  |
| 31         | 1 месяц                   |
| 4          | 1 квартал                 |

## Поля JSON-ответа

Массив объектов:

| Поле     | Тип      | Обязательно | Смысл                                                   |
| -------- | -------- | ----------- | ------------------------------------------------------- |
| `open`   | float    | да          | Цена открытия                                           |
| `close`  | float    | да          | Цена закрытия                                           |
| `high`   | float    | да          | Максимум                                                |
| `low`    | float    | да          | Минимум                                                 |
| `value`  | float    | да          | Оборот в валюте (₽)                                     |
| `volume` | int      | нет         | Объём в штуках (отсутствует в части групп)              |
| `begin`  | datetime | да          | Начало интервала свечи                                  |
| `end`    | datetime | нет         | Конец интервала свечи (для дневных может отсутствовать) |

## Edge cases

- Если торговля шла в нескольких основных режимах в один интервал — может быть несколько свечей (по одной на режим). Чтобы избежать дублей — используй [`get_board_candles`](get_board_candles.md).
- `end` без значения и сегодняшняя дата → последняя свеча будет **недозакрытой**.
- Доступные интервалы — через [`get_market_candle_borders`](get_market_candle_borders.md).

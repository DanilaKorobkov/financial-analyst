# Git

В проекте **не используем** `git rebase` и любые виды force-push (`--force`, `--force-with-lease`).

Почему:
- история коммитов остаётся честной и линейно-наращиваемой;
- ничего не «исчезает» из remote — ревью и обсуждения всегда остаются на видимых коммитах;
- исключаем риск перезаписать чужую работу на общей ветке.

Как разрешать расхождение с `main`:
- `git merge origin/main` (мердж-коммит — это нормально),
- либо мердж `main` через PR на GitHub (кнопкой «Update branch»).

Никогда:
- `git rebase` (включая интерактивный),
- `git push --force` / `--force-with-lease`,
- `git commit --amend` для уже запушенных коммитов,
- `git reset --hard` (включая откат локального состояния — данные могут пропасть безвозвратно; используем `git revert`, `git restore` или мердж-коммит).

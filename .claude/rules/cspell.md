# cspell

Когда `task lint-cspell` ругается на слово — **не добавляй его в словарь рефлекторно**. Сначала классифицируй и реши: править текст или расширять словарь.

## Алгоритм принятия решения

1. **Опечатка** → исправить в тексте. В словарь не добавлять.

2. **Транслитерированный англицизм**, у которого есть либо латинский оригинал, либо родное русское слово → **исправить в тексте**, не добавлять в словарь:

   - `плейсхолдер` → `placeholder` либо «значение подстановки» / «параметр пути».
   - `скилл` → `skill` либо «справочник» / «навык».
   - `пагинирует`, `пагинируется`, `пагинируются` → «разбит на страницы» / `paginated`.
   - `бенчмарк` → `benchmark` либо «эталон».
   - `моментум` → `momentum` либо «импульс».
   - `пайплайн` → `pipeline` либо «конвейер».
   - `дашборд` → `dashboard` либо «панель».
   - `фича` → `feature` либо «возможность».

   Правило: если слово целиком пишется латиницей в технической документации индустрии — пиши латиницей. Если есть устоявшийся русский эквивалент — пиши по-русски.

3. **Устоявшийся доменный термин на русском**, которого нет в общем словаре `ru_ru` (специальная финансовая / биржевая лексика, не передаваемая ни одним коротким эквивалентом) → **добавить в словарь**:

   - `МСФО`, `РСБУ`, `эмитент`, `мажоритарий`, `мультипликатор`.
   - `субиндекс`, `ребалансировка`, `редомициляция`, `депозитарная расписка`.
   - Критерий: слово используется в профильной литературе и нормативке РФ; «перевод» на родной русский был бы искусственным.

4. **Аббревиатура / тикер / код режима / имя поля API / название бренда** → **добавить в словарь**:

   - Тикеры MOEX: `SBER`, `GAZP`, `LKOH`, `YDEX`.
   - Коды режимов: `TQBR`, `TQOB`, `SELT`.
   - Финансовые аббревиатуры: `EBITDA`, `EBIT`, `ROIC`, `CAPEX`.
   - Имена полей API: `NUMTRADES`, `WAPRICE`, `ISQUALIFIEDINVESTORS`.
   - Имена брендов / сервисов: `FinanceMarker`, `Refinitiv`.

5. **Сомневаешься между п.2 и п.3?** Применяй критерий: «существует ли в индустрии русский технический эквивалент, который не звучит искусственно?» Если да — пиши по-русски и исправляй в тексте. Если нет — добавляй в словарь.

## Где словарь

`.cspell/project.txt` — одно слово на строку, `#` — комментарий. Группируй по разделам с заголовками, чтобы было видно, что и зачем добавлено.

## Что НЕ делать

- Не добавлять в словарь падежные/числовые формы транслитерированных англицизмов (`плейсхолдеров`, `пагинируются`) — это удваивает ошибку.
- Не глушить cspell через `cspell:disable` / inline-комментарии — словарь должен быть единым источником правды.
- Не добавлять опечатки, даже если их встретилось несколько — исправляй источник.
